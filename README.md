# day-part-speech

Read text aloud with the platform’s speech engine.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

Use a callback or future to observe completion, and stop speech explicitly when needed.
Completion reporting and voice selection vary by platform.

## Use

Add `day-part-speech = "0.*"` to your app’s `[dependencies]`.
Follow the setup guide for platform requirements and initialization.
